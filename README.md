# Редактор курсов

Браузерный прототип редактора уроков в духе Stepik, рассчитанный на вставку материалов из ChatGPT.

## Как запустить

Откройте \`index.html\` в современном браузере. Сервер, сборка и внешние библиотеки не нужны.

## Возможности

- Кнопка **«Копировать оформление»** отправляет в буфер одновременно `text/html` и `text/plain` для вставки с форматированием в другие редакторы (включая совместимые режимы Stepik). Кнопка **«HTML-код»** копирует исходную разметку.
- Визуальный редактор с панелью: заголовки, выделение, выравнивание, списки, цитаты, код, ссылки и разделители.
- Вставка HTML из буфера обмена с очисткой потенциально опасных элементов и атрибутов.
- Если ChatGPT предоставил в буфере только текст/Markdown, базовая Markdown-разметка преобразуется в HTML (переключается).
- Три режима: визуальное редактирование, HTML-исходник, предпросмотр.
- Несколько уроков в одном проекте: создание, переключение, переименование.
- Локальное автосохранение в \`localStorage\`.
- Экспорт текущего урока в самостоятельный HTML, экспорт и импорт всего проекта в JSON, импорт HTML урока.

## Цвет текста и изображения

- Панель форматирования закреплена под верхней шапкой при прокрутке длинного урока.
- Выделите текст и нажмите **A** с цветной полосой: можно выбрать готовый цвет, задать свой или нажать «Сбросить цвет». При возвращении курсора на окрашенный фрагмент кнопка показывает текущий цвет.
- Для вставки картинки поставьте курсор в текст урока, скопируйте изображение и нажмите **Ctrl+V**. Также есть кнопка ▧ для выбора файла PNG, JPEG, WebP или GIF. Содержимое изображения встраивается непосредственно в HTML урока.
- Щёлкните по картинке: появятся кнопки **− / +** для изменения её ширины. Стандартные кнопки выравнивания переместят изображение влево, по центру или вправо.
- Для уменьшения размера проекта изображения могут автоматически сжиматься; для одного изображения установлен предел примерно 1,5 МБ. Автосохранение по-прежнему зависит от лимита `localStorage` браузера, поэтому при работе с изображениями особенно важно экспортировать резервную копию в JSON. Экспорт HTML включает изображения прямо в файл.

## Многострочные блоки кода

- Блоки `<pre><code>` в **визуальном редакторе** доступны для выделения и копирования, но недоступны для прямого набора и форматирования. Двойной щелчок по блоку открывает отдельное окно редактирования.
- Окно поддерживает **GDScript** (по умолчанию, с подсветкой прямо во время ввода в поле кода) и **No Highlight** (без подсветки). Дополнительного окна предпросмотра подсветки нет. Выбор сохраняется в атрибуте `data-language` блока и попадает в HTML/JSON.
- Исходный код редактируется только в диалоге: **Применить** сохраняет содержимое, **Отменить** отменяет изменения. Щелчок вне окна и Escape его не закрывают.
- Клавиша **Tab** добавляет настоящую табуляцию, **Shift+Tab** снимает отступ; **Enter** сохраняет текущий отступ и добавляет табуляцию после строки GDScript, заканчивающейся на двоеточие (`func`, `if`, `else` и т. п.). Если курсор стоит в начале строки внутри отступа, один **Backspace** убирает сразу один символ табуляции либо до четырёх пробелов.
- Вкладка **HTML** остаётся отдельным режимом непосредственного редактирования исходной HTML-разметки урока.

## Важные ограничения

Это **локальный прототип**, не опубликованная LMS. Нет регистрации, общего облачного хранения, совместного редактирования, приема оплаты и привязки к Stepik API. Сохраненные данные находятся только в текущем браузере/профиле и могут пропасть при очистке хранилища — пользуйтесь экспортом JSON.

Вставка HTML проходит через собственный allowlist-санайзер: скрипты, обработчики событий, iframe, формы и произвольные атрибуты удаляются. HTML в режиме предпросмотра дополнительно отображается в sandboxed iframe. Поддерживается распространенная текстовая разметка и таблицы; произвольные inline-стили, интерактивные элементы, изображения и сложное оформление могут быть удалены. Это защитный компромисс для прототипа, а не замена проверенной серверной очистке HTML в публичном приложении.
