# Редактор курсов

Редактор курсов IndieForge с иерархией «курс → модули → уроки → шаги» и переключением шагов по принципу Stepik. Сохраняет возможности вставки и оформления материалов из ChatGPT.

## Как запустить

Откройте `index.html` в современном браузере или запустите локальный сервер:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Сборка и сервер приложений не нужны. Все возможности работают на HTML, CSS и JavaScript.

## Разработчик и ученик

В общей шапке переключается вид всего курса: **Разработчик / Ученик**.

- Разработчик редактирует структуру, конспекты и задания. Для конспекта доступны «Редактор» и «HTML»; отдельной вкладки предпросмотра нет.
- Ученик видит оглавление курса и материалы без кнопок создания, настроек, перетаскивания, HTML, импорта и экспорта. Можно читать конспекты, отвечать на задания и переходить между шагами, уроками и модулями.
- Конспект отмечается кнопкой «Отметить шаг пройденным», задание — после правильного ответа. В оглавлении и на карточках шагов виден прогресс. На границе уроков кнопки навигации переходят в соседний урок.
- Ответы и прогресс пробного прохождения сохраняются при переходах и переключении видов до обновления страницы. Изменение материала или настройки задания сбрасывает его пробный результат. Эти данные не входят в JSON курса.
- При включении вида ученика последние правки сохраняются. Возврат к разработчику восстанавливает визуальный редактор или HTML.

## Структура курса

- Оглавление находится слева. Название курса редактируется над ним; на узком экране оглавление открывается слева кнопкой ☰.
- Курс состоит из модулей, модуль — из уроков. «Добавить урок» в конце раскрытого модуля создаёт урок именно в нём. «Добавить модуль» расположена под всем списком.
- Перетаскивайте модули и уроки за маркер ⠿. Урок можно перенести в другой модуль, включая пустой или свёрнутый: после переноса он раскроется. Линия показывает место вставки, рамка — перенос внутрь модуля. Поддерживаются мышь и сенсорный экран, прокрутка длинного списка, отмена клавишей Escape. Для клавиатуры: на маркере Alt + ↑ / ↓ меняют порядок, Alt + ← / → переносят урок в соседний модуль.
- Меню «⋯» у модуля и «⋮» у урока позволяют переименовать и изменить порядок. Название урока меняется только через это меню: в открытом уроке поля переименования нет. Урок можно перенести в другой модуль, дублировать со всеми шагами или удалить. Удалять можно только пустые модули; последний модуль и последний урок защищены от удаления.
- Над содержимым урока расположены пронумерованные шаги с обозначением типа. Доступны переходы кнопками, стрелками клавиатуры в списке шагов и кнопками «Предыдущий / Следующий шаг». Порядок шагов можно менять перетаскиванием их карточек. Открытый шаг и его содержимое при переносе сохраняются.
- У каждого шага своё содержимое, а обозначение определяется выбранным типом: «Конспект», «Один ответ» и т. д. Поля переименования шага нет. Перемещение, дублирование и удаление доступны в компактном меню «⋮» рядом с «Добавить шаг»; последний шаг остаётся в уроке.

### Типы шагов

**Конспект**: визуальный редактор и HTML в виде разработчика, чтение материала в виде ученика. Поддерживаются вставка форматированного HTML, преобразование Markdown, заголовки, списки, таблицы, ссылки, изображения и блоки кода.

**Задания**: один ответ, несколько ответов, сопоставление, сортировка, таблица, пропуски, числовой и текстовый ответ. Разработчик настраивает условие, правильные ответы, баллы, погрешность числа и чувствительность текста к регистру. В виде ученика доступны ввод и проверка ответа. Неполная конфигурация задания блокирует проверку; подсказка о настройке показывается разработчику.

## Сохранение и обмен

- Курс, модули, уроки, шаги и открытый шаг каждого урока сохраняются локально в `localStorage`.
- «Экспорт курса» скачивает JSON со всей структурой и заданиями. Импорт JSON заменяет текущий курс после подтверждения; сначала сохраните резервную копию.
- Старые проекты без шагов автоматически преобразуются: HTML каждого урока становится первым конспектом. Импортированный HTML добавляется отдельным уроком в текущий модуль.
- «HTML шага» выгружает текущий конспект в самостоятельный HTML. Задания передаются в JSON; их HTML-экспорт не предусмотрен.
- «Копировать оформление» и «HTML-код» копируют текущий конспект.
- Ограничения: 100 модулей, 300 уроков, 150 шагов в уроке, 100 элементов в списках задания, импорт до 3 МБ. Ёмкость локального хранения зависит от браузера.

## Проверки

```bash
npm install --package-lock=false --no-audit --no-fund
npx playwright install chromium
npm test
```

Если Chromium уже установлен в системе:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

Playwright запускает локальный сервер автоматически. `tests/editor.spec.cjs` проверяет форматирование, код, вставку и изображения; `tests/course.spec.cjs` — структуру курса, шаги, все типы заданий, сохранение, миграцию, импорт/экспорт и мобильную навигацию; `tests/reorder.spec.cjs` — перетаскивание и сохранение содержимого после переноса; `tests/course-view.spec.cjs` — общий вид ученика, отсутствие редактирования, прогресс, переходы между уроками, ответы и возврат к исходному HTML.

## Цвет текста и изображения

- Панель форматирования закреплена под верхней шапкой при прокрутке длинного урока.
- Выделите текст и нажмите **A** с цветной полосой: можно выбрать готовый цвет, задать свой или нажать «Сбросить цвет». При возвращении курсора на окрашенный фрагмент кнопка показывает текущий цвет.
- Для вставки картинки поставьте курсор в текст урока, скопируйте изображение и нажмите **Ctrl+V**. Также есть кнопка ▧ для выбора файла PNG, JPEG, WebP или GIF. Содержимое изображения встраивается непосредственно в HTML урока.
- Щёлкните по картинке: появятся кнопки **− / +** для изменения её ширины. Стандартные кнопки выравнивания переместят изображение влево, по центру или вправо.
- Для изменения размера мышью наведите указатель на изображение: по четырём углам появятся квадратные маркеры с диагональным курсором. Потяните за угол, чтобы увеличить или уменьшить картинку с сохранением пропорций. Новый размер сохраняется в HTML урока, но сами маркеры в документ не попадают.
- Для уменьшения размера проекта изображения могут автоматически сжиматься; для одного изображения установлен предел примерно 1,5 МБ. Автосохранение по-прежнему зависит от лимита `localStorage` браузера, поэтому при работе с изображениями особенно важно экспортировать резервную копию в JSON. Экспорт HTML включает изображения прямо в файл.

## Многострочные блоки кода

- Блоки `<pre><code>` в **визуальном редакторе** доступны для выделения и копирования, но недоступны для прямого набора и форматирования. Двойной щелчок по блоку открывает отдельное окно редактирования.
- Окно поддерживает **GDScript** (по умолчанию, с подсветкой прямо во время ввода в поле кода) и **No Highlight** (без подсветки). Дополнительного окна предпросмотра подсветки нет. Выбор сохраняется в атрибуте `data-language` блока и попадает в HTML/JSON.
- Исходный код редактируется только в диалоге: **Применить** сохраняет содержимое, **Отменить** отменяет изменения. Щелчок вне окна и Escape его не закрывают.
- Клавиша **Tab** добавляет настоящую табуляцию, **Shift+Tab** снимает отступ; **Enter** сохраняет текущий отступ и добавляет табуляцию после строки GDScript, заканчивающейся на двоеточие (`func`, `if`, `else` и т. п.). Если курсор стоит в начале строки внутри отступа, один **Backspace** убирает сразу один символ табуляции либо до четырёх пробелов.
- Вкладка **HTML** остаётся отдельным режимом непосредственного редактирования исходной HTML-разметки урока.

## Важные ограничения

Это **локальный прототип**, не опубликованная LMS. Нет регистрации, общего облачного хранения, совместного редактирования, приема оплаты и привязки к Stepik API. Сохраненные данные находятся только в текущем браузере/профиле и могут пропасть при очистке хранилища — пользуйтесь экспортом JSON.

Вставка HTML проходит через собственный allowlist-санайзер: скрипты, обработчики событий, iframe, формы и произвольные атрибуты удаляются. HTML в режиме предпросмотра дополнительно отображается в sandboxed iframe. Поддерживается распространенная текстовая разметка и таблицы; произвольные inline-стили, интерактивные элементы, небезопасные изображения и сложное оформление могут быть удалены. Это защитный компромисс для прототипа, а не замена проверенной серверной очистке HTML в публичном приложении.

Для будущей интеграции с платформой на Python / Django / PostgreSQL структура данных выделена в `course-model.js` (версия JSON — 3). Серверная авторизация, хранение и проверка заданий ещё не подключены. Проверка в предпросмотре выполняется в браузере автора и не предназначена для защиты ответов от учеников.
